ANDROID · CARPLAY · ESP32 BLE

DiPlay 手机融合仪表

基于 DiPlay 手机适配版继续开发，让 Android 手机同时呈现 CarPlay 副屏地图、车辆仪表与音乐信息。支持主副屏切换、2:1 显示预设和日夜主题，并通过 ESP32 BLE 接收车辆数据。

改编项目；公开分支源码与 Debug APK，车辆数据仍待实车验收

RK3399 · ANDROID · ALPINE

RK3399 Android NAS

将已 root 的 RK3399 Android 设备变成多盘 NAS，提供 SMB、FTP、SFTP、WebDAV 和网页文件管理。配套脚本负责首次安装与升级，支持 USB 磁盘管理、局域网发现和 SSH 管理。

公开部署源码与文档；新版首次安装完整流程仍待验收

RK3399 · ANDROID · KOTLIN

RK3399 Control

运行在 RK3399 板端的 Android 控制台，集中管理 NAS 服务、Wi-Fi 热点、有线网络、路由与 USB 存储。提供经过密码认证的局域网接口，可与手机工具箱配合进行远程控制。

公开源码与 Debug 预览 APK；需已 root 的配套板端环境

ANDROID · NETWORK · KOTLIN

RK3399 网络工具箱

手机端的 RK3399 配套工具，支持自动发现设备、iperf3 测速，以及 SMB、FTP、SFTP 文件浏览与传输。连接板端控制台后，还能远程管理服务、网络和 USB 存储；手机无需 root。

公开源码与构建说明；支持 Android 9 及以上

ESP32 车辆仪表

基于 CAN / RS485 的 ESP32 车辆仪表固件，在彩屏显示速度、挡位、电量、功率与车辆状态。新增 BLE 车辆遥测，可配合 DiPlay 手机融合仪表使用，并保留 WiFi OTA 升级；仓库提供固件、接线资料和使用说明。

  • ST7789 屏幕
  • BLE / WiFi OTA
  • 固件与接线文档
