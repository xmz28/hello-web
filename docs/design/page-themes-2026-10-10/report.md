# 按页面调整日夜模式

本次按用户逐页确认的要求调整，保留已有布局、玻璃透明度层次、渐变和插画色彩。签证、终端与 SSH 外观不在本次调整范围。

| 页面 | 日间 | 夜间 |
| --- | --- | --- |
| 首页 | 保留现有外观 | 加深照片遮罩和底部玻璃面板 |
| 个人页 | 背景和蓝色玻璃面板略提亮 | 补充更深的蓝色背景和面板 |
| 博客 | 保留现有外观 | 背景、正文、筛选、弹窗和评论区跟随夜间 |
| 我的作品 | 新增浅蓝透光面板与深色文字 | 减轻原来过暗的背景遮罩，提亮卡片 |
| 小游戏 | 框内面板、按钮和画布改为浅蓝色与深色文字 | 保留原有框内深色配色 |
| 网站导航 | 玻璃面板稍调暗，提高白色文字对比度 | 保留原有外观 |
| 状态面板 | 背景和面板稍提亮 | 补充深蓝玻璃面板和背景 |

小游戏页面背景的既有日夜行为保持原样。贪吃蛇、俄罗斯方块和 Flappy 的画布颜色随主题切换；五子棋木色棋盘和棋子、2048 数字块保留原有识别配色。主题切换只重绘，不重开游戏、不清空得分，也不改变计时器或暂停状态。

## 验证

- 浏览器逐页验证 7 页日间和夜间的背景、面板、正文样式，并保存两种模式截图。
- 390×844 手机视口检查 7 页两种模式，未发现页面横向溢出。属于视口模拟，未替代实体手机检查。
- `node tools/test-site-settings.cjs` 通过：设置、自动模式、跨标签同步、评论区配置、语言数据保护及页面脚本语法。
- `node tools/test-games.cjs` 通过：游戏生命周期和触屏回归，新增主题重绘后棋盘、得分、暂停与计时器保留检查。
- 下载版 Windows 路由助手重新构建；内嵌样式与源文件一致，分片重组、EXE 大小和 SHA256 校验一致。
- `git diff --check` 通过。浏览器验证结束后恢复自动主题和默认视口。
